# Personal React Project

Навчальний React-проєкт, створений для демонстрації навичок роботи з React, React Router, Material UI, Tailwind CSS та API.

## Технології

- React
- React Router
- Material UI (MUI)
- Tailwind CSS
- OpenWeather API

---

## Сторінки проєкту

### /about — Про мене
Сторінка містить:
- коротку інформацію про мене;
- мої цінності, захоплення та досвід навчання;
- блок із проєктами:
    - HTML + CSS
    - JavaScript
    - React

---

### /my-city — Моє місто
Сторінка з описом міста та погодою через API.

Реалізовано:
- API-запит через `useEffect`
- збереження даних у `useState`
- відображення:
    - температури;
    - опису погоди;
    - координат;
    - назви міста та країни.

---

### /my-future — Мій розвиток
Сторінка про професійні цілі та майбутнє.

Містить:
- 3 кроки професійного розвитку;
- мотиваційну цитату;
- опис роботи мрії;
- timeline через Material UI.
